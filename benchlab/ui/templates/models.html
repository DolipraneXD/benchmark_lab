Roles

Three settings name a model. A model holding one of them can't be deleted or renamed until another model takes the role.

Changing the baseline changes every comparison in the report. Changing the simulator makes new τ² scores incomparable with older ones.

API keys

Keys are saved in .env in this folder, readable by you only and never committed. The panel and terminal runs both read them from there. A saved key is never shown again, only its last 4 characters; to change one, paste the new key over it.
